# ILLIA — Персональне портфоліо

Персональний сайт-візитка Іллі: студента Полтавського політехнічного коледжу, Python-розробника та ентузіаста технологій.

На сайті можна дізнатися про мене, мої навички, проєкти (Telegram-боти та невеликі програми на Python) і мої захоплення. Усі проєкти з посиланням на GitHub: [github.com/Hatewrld4](https://github.com/Hatewrld4).

## Як переглянути сайт

**Онлайн:** відкрий посилання, яке надіслав автор.

**На своєму комп'ютері:**
1. Завантаж репозиторій (кнопка «Code» → «Download ZIP») і розпакуй архів.
2. Відкрий файл `index.html` у будь-якому браузері.

Якщо сторінка відкрилась без стилів або анімацій, запусти локальний сервер:

```bash
cd illia-portfolio
python -m http.server 8000
```

Потім відкрий у браузері `http://localhost:8000`.

## Структура проєкту

```
illia-portfolio/
├── index.html          # головна сторінка
├── css/style.css       # стилі
├── js/script.js        # інтерактивність (меню, анімації)
├── assets/images/      # зображення
├── favicon.svg         # іконка вкладки
└── README.md           # цей файл
```
